# Dependencies

- Host: [Gen1Recomp 0.2.36](https://github.com/bryanthaboi/gen1recomp/releases/tag/v0.2.36), commit `fc56b9b05f01c559610c71f801355abfa4ae920f`, plus the compatibility patches included here.
- Runtime: LÖVE 11.x (installed tests used the existing game runtime); Python 3 for the installer.
- Optional display: [Deck Tilt 0.9.2](https://github.com/kaboggs/deck-tilt-mod/releases/tag/v0.9.2).
- Optional Stadium effects: [StadiumBattleFX 2.1.8.1](https://github.com/anxiousintrovert/StadiumBattleFX/releases/tag/v2.1.8.1), plus the [compatibility fixes](https://github.com/kaboggs/dramatic-mini-modifications-mod/tree/v0.1.1/optional/stadium-local-fixes). Game data is imported from your own compatible backups.
- Optional voxel rendering: Dramatic Shape 1.8.1 is included with [Mini 0.1.1](https://github.com/kaboggs/dramatic-mini-modifications-mod/releases/tag/v0.1.1). Original source and third-party notices are retained in that package.

Versions are pinned. Installation does not fetch newer dependencies. Supply your own compatible game backups; this project includes no ROMs or extracted game data.
